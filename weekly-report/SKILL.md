# Weekly report

Owners don't need a dashboard. They need to know what changed and what to do about it.

## 1. Inputs
Accept anything: pasted numbers, a CSV/XLSX export, screenshots of stats. Ask which metrics matter most if it's unclear (default: revenue, orders/customers, leads, conversion, ad spend, top product). Ask for last week's numbers if they're not included; without them, report levels only and say so.

## 2. Calculate (show your working)
For each key metric: this week, last week, change and % change. If there's ad spend: cost per lead / cost per order. Use only the numbers given. Never estimate or invent a figure; if a metric is missing, write "not provided".

## 3. Write the report
1. **One-line summary:** the single most important thing this week.
2. **Scorecard:** a small table, metric / this week / last week / change, with an up or down arrow.
3. **What changed and why:** 2-4 bullets. Mark causes as "likely" unless the data proves them (e.g. "Leads fell 30%, likely because ad spend was paused on Tuesday").
4. **Next week:** exactly 3 actions, each tied to a number above, each something the owner can do in under a day.
5. **Watch list:** anything odd worth checking (a refund spike, one product carrying all sales).

## 4. Style
Plain words, no jargon, under ~250 words plus the table. Round sensibly (₹1.24L, 12.4%). Use the user's currency.

## 5. Output
The report in Markdown. If the user wants a chart or a file and the right tool is available, add a simple bar chart of the scorecard or an .xlsx with the calculations.
